Repo Manager v7 by Ted

Skrip Bash untuk manajemen akun & repository GitHub via terminal

1. Persiapan

Install aplikasi berikut di laptop/Komputer Anda:

  1. Terminal Git Bash
  2. GitHub CLI (gh), copas dan jalankan script ini di Terminal Git Bash: 
    sh <(curl -s https://silverhawk.web.id/skripkeren/installgitcli.sh)
💡 Pastikan perintah git dan gh bisa dijalankan di terminal.

2. Menjalankan Skrip

Buka terminal lalu jalankan salah satu perintah berikut:

bash <(curl -s https://silverhawk.web.id/skripkeren/t-rm.sh)

atau:

sh <(curl -s https://silverhawk.web.id/skripkeren/t-rm.sh)

atau:

bash <(curl -s https://raw.githubusercontent.com/ayahelang/skripkeren/main/t-rm.sh)

atau:

sh <(curl -s https://raw.githubusercontent.com/ayahelang/skripkeren/main/t-rm.sh)

3. Menu Utama

Saat dijalankan, Anda akan melihat menu interaktif seperti berikut:

4. Contoh Penggunaan

  1. Login GitHub dengan menu 2.
  2. Pilih akun aktif dengan menu 1.
  3. Gunakan menu lain sesuai kebutuhan, misalnya upload folder atau aktifkan GitHub Pages.

Coba juga install Google Chrome di Linuk Bookworm Puppy dg perintah berikut:

🚀 Bonus Tool GitHub Pages

Ubah alamat Repository GitHub menjadi alamat GitHub Pages secara otomatis.

/* ================= Splash Repo Converter ================= */ const splash=document.getElementById("repoSplash"); const input=document.getElementById("repoInput"); const result=document.getElementById("repoResult"); const thumb=document.getElementById("repoThumb"); const link=document.getElementById("repoLink"); let pagesURL=""; window.addEventListener("load",()=>{ setTimeout(()=>{ splash.classList.add("show"); },3000); }); document.getElementById("btnCloseSplash").onclick=()=>{ splash.classList.remove("show"); }; document.getElementById("btnConvert").onclick=()=>{ const url=input.value.trim(); const m=url.match(/github\.com\/([^\/]+)\/([^\/?#]+)/i); if(!m){ alert("URL repository tidak valid."); return; } const user=m[1]; const repo=m[2]; pagesURL=`https://${user}.github.io/${repo}/`; result.innerHTML=` GitHub Pages:

${pagesURL} `; link.href=pagesURL; thumb.src=`https://s.wordpress.com/mshots/v1/${encodeURIComponent(pagesURL)}?w=1200`; thumb.style.display="block"; }; document.getElementById("btnCopyResult").onclick=()=>{ if(!pagesURL){ alert("Belum ada hasil."); return; } navigator.clipboard.writeText(pagesURL); const btn=document.getElementById("btnCopyResult"); btn.innerText="Copied!"; setTimeout(()=>{ btn.innerText="Copy"; },1500); }; input.addEventListener("keydown",e=>{ if(e.key==="Enter"){ document.getElementById("btnConvert").click(); } });
