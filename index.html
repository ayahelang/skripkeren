Kumpulan skrip Bash untuk manajemen repository GitHub — jalan di Desktop, Codespaces, maupun terminal online

1. Persiapan (opsional di Codespaces)

Di GitHub Codespaces biasanya git dan curl sudah ada. Di laptop, siapkan:

  1. Terminal Git Bash (Windows) atau Terminal biasa (macOS/Linux)
  2. GitHub CLI (gh) — disarankan agar login lebih mudah: 
    bash <(curl -fsSL https://skripkeren.silverhawk.web.id/installgitcli.sh)
💡 t-rm.sh bisa jalan tanpa gh (pakai token/PAT). Tapi dengan gh, login bisa lewat browser tanpa tempel token manual.

2. Silverhawk AutoCLI — t-rm.sh

All-in-one: login, pilih repo, file manager (browse/upload/hapus), buat/rename/hapus repo, GitHub Pages.

Jalankan di mana saja (Desktop / Codespaces / Copilot terminal):

bash <(curl -fsSL https://skripkeren.silverhawk.web.id/t-rm.sh)

atau unduh dulu:

curl -fsSL https://skripkeren.silverhawk.web.id/t-rm.sh -o t-rm.sh && bash t-rm.sh

Login (otomatis menyesuaikan lingkungan)

  • Codespaces — coba pakai GITHUB_TOKEN otomatis
  • Desktop + gh sudah login — ambil sesi gh auth
  • Lainnya — pilih di menu:
    1. Auto-detect lagi
    2. Login via GitHub CLI (browser / device code) — disarankan
    3. Tempel PAT manual
    4. Panduan buat PAT
⚠️ GitHub tidak mengizinkan login API hanya dengan username + password. Gunakan PAT atau gh auth login.

4. Restore / Rollback commit — restore.sh

Kembalikan repo ke commit (titik sejarah) sebelumnya. Aman dipakai lewat curl | bash (input dari terminal asli).

  1. Buka terminal di dalam folder repository (Codespaces atau lokal).
  2. Jalankan:
curl -fsSL https://skripkeren.silverhawk.web.id/restore.sh | bash

atau:

curl -fsSL https://skripkeren.silverhawk.web.id/restore.sh -o restore.sh && chmod +x restore.sh && ./restore.sh
Script menampilkan info akun/repo/branch, daftar 25 commit, lalu Anda pilih nomor.
Konfirmasi wajib ketik YA sebelum reset --hard + push --force.

5. Urus Repo — urusrepo.sh

Script interaktif untuk membersihkan repo, rename massal file (web-safe), dan menyamakan isi lokal ↔ GitHub. Otomatis menyesuaikan lingkungan: Codespaces atau Git Bash / desktop.

Developed by James What

Jalankan di mana saja (Codespaces / Git Bash / terminal):

bash <(curl -fsSL https://skripkeren.silverhawk.web.id/urusrepo.sh)

atau unduh dulu:

curl -fsSL https://skripkeren.silverhawk.web.id/urusrepo.sh -o urusrepo.sh && chmod +x urusrepo.sh && bash urusrepo.sh

Perilaku per lingkungan

  • Codespaces — langsung menu; repo aktif = folder Codespaces saat ini
  • Git Bash / desktop — wizard login (username + PAT), pilih nomor repo dari daftar, lalu menu

Menu utama

  1. Kosongkan isi repo — hapus semua di root kecuali CNAME, file *.sh, dan exclude opsional yang Anda ketik
  2. Rename massal folder — spasi→underscore, pecah CamelCase, lowercase, buang karakter khusus; bentrok dilengkapi nomor leading zero. Bisa juga pakai nama dasar kustom + nomor
  3. Samakan lokal ← GitHub — fetch + reset --hard ke origin (perubahan lokal belum di-push bisa hilang)
  4. Samakan GitHub ← lokal — git add -A + commit + push (termasuk menghapus file yang tidak ada di lokal)
  5. Ganti / pilih repo — ulangi wizard login
  6. Upload lokal → GitHub (keep remote) — tambah & update file dari lokal, tanpa menghapus file/folder yang hanya ada di GitHub
⚠️ Menu kosongkan & reset bersifat merusak data lokal — selalu ada konfirmasi y/N. Pakai Personal Access Token (PAT) scope repo, bukan password akun GitHub.

6. Reveal Password WiFi

Menampilkan password WiFi yang sudah pernah terhubung & tersimpan.

Windows — wifi-pass.ps1

PowerShell (disarankan jalankan sebagai Administrator):

irm https://skripkeren.silverhawk.web.id/wifi-pass.ps1 | iex

Dari CMD (as Administrator):

powershell -ExecutionPolicy Bypass -Command "irm https://skripkeren.silverhawk.web.id/wifi-pass.ps1 | iex"

Atau unduh dulu:

irm https://skripkeren.silverhawk.web.id/wifi-pass.ps1 -OutFile wifi-pass.ps1
powershell -ExecutionPolicy Bypass -File .\wifi-pass.ps1
Menampilkan password WiFi aktif + daftar semua profil tersimpan yang bisa dipilih.

Linux / Termux / Android — wifi-pass.sh

bash <(curl -fsSL https://skripkeren.silverhawk.web.id/wifi-pass.sh)

atau unduh dulu:

curl -fsSL https://skripkeren.silverhawk.web.id/wifi-pass.sh -o wifi-pass.sh
chmod +x wifi-pass.sh && ./wifi-pass.sh
⚠️ Di Android butuh root untuk membaca password. Tanpa root hanya bisa melihat SSID yang sedang terhubung (jika tersedia). Di Linux biasa biasanya butuh sudo.

8. Home Server Ubuntu — lserver.sh

Script menu interaktif untuk membangun server rumahan di Ubuntu Server (laptop jadul / PC bekas). Cocok dijalankan di terminal saja (tanpa GUI). Target default subdomain: lserver.silverhawk.web.id.

Jalankan di Ubuntu Server (disarankan pakai sudo):

sudo bash <(curl -fsSL https://skripkeren.silverhawk.web.id/lserver.sh)

atau unduh dulu:

curl -fsSL https://skripkeren.silverhawk.web.id/lserver.sh -o lserver.sh
chmod +x lserver.sh
sudo ./lserver.sh

Menu yang tersedia

  1. Update sistem + tools dasar — apt update/upgrade, curl, git, jq, htop, ufw, fail2ban, dll.
  2. Firewall (UFW) + Fail2ban — buka SSH/80/443, aktifkan proteksi brute-force.
  3. Install Docker — lewat get.docker.com resmi.
  4. Cloudflare Tunnel — install cloudflared + panduan token/service untuk lserver.silverhawk.web.id.
  5. Install PocketBase — real-time database + auth + admin UI (cocok untuk CRM / Marketplace).
  6. Nginx reverse proxy (opsional) — proxy ke PocketBase di port 80.
  7. Status layanan — cek apa saja yang sudah jalan.
  8. Info CRM + contoh collection — penjelasan singkat + struktur data Marketplace.
  9. Panduan DNS Domainesia — cara tambah CNAME tanpa mengubah Nameserver (supaya subdomain GitHub Pages lain aman).
💡 Nameserver domain tetap di Domainesia. Hanya tambah record CNAME lserver mengarah ke hostname Cloudflare Tunnel. Dengan begitu skripkeren.silverhawk.web.id dan subdomain GitHub Pages lainnya tidak terganggu.

9. Home NAS (CasaOS) — lnas.sh

Script menu interaktif untuk membangun NAS rumahan berbasis CasaOS di Ubuntu Server. Cocok laptop/PC bekas. Bisa digabung dengan lserver.sh (subdomain terpisah).

Jalankan di Ubuntu Server (disarankan pakai sudo):

sudo bash <(curl -fsSL https://skripkeren.silverhawk.web.id/lnas.sh)

atau unduh dulu:

curl -fsSL https://skripkeren.silverhawk.web.id/lnas.sh -o lnas.sh
chmod +x lnas.sh
sudo ./lnas.sh

Menu yang tersedia

  1. Persiapan sistem — update + tools (curl, samba, smartmontools, dll.)
  2. Firewall UFW — SSH, web (80/443), Samba (445/139)
  3. Install Docker — wajib untuk CasaOS
  4. Install CasaOS — installer resmi get.casaos.io
  5. Info storage & disk — lsblk, df, saran mount
  6. Samba share cepat (opsional) — share folder di luar CasaOS
  7. Cloudflare Tunnel untuk NAS — contoh subdomain nas.silverhawk.web.id
  8. Status layanan & container
  9. Panduan & tips
💡 CasaOS memberi UI modern + App Store (Nextcloud, Jellyfin, PhotoPrism, dll.). Nameserver tetap di Domainesia; cukup tambah CNAME nas ke Cloudflare Tunnel.
