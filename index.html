Kumpulan skrip Bash untuk manajemen repository GitHub — jalan di Desktop, Codespaces, maupun terminal online

1. Persiapan (opsional di Codespaces)

Di GitHub Codespaces biasanya git dan curl sudah ada. Di laptop, siapkan:

  1. Terminal Git Bash (Windows) atau Terminal biasa (macOS/Linux)
  2. GitHub CLI (gh) — disarankan agar login lebih mudah: 
    bash <(curl -fsSL https://skripkeren.silverhawk.web.id/installgitcli.sh)
💡 t-rm.sh bisa jalan tanpa gh (pakai token/PAT). Tapi dengan gh, login bisa lewat browser tanpa tempel token manual.

2. Silverhawk AutoCLI — t-rm.sh

All-in-one: login, pilih repo, file manager (browse/upload/hapus), buat/rename/hapus repo, GitHub Pages.

Jalankan di mana saja (Desktop / Codespaces / Copilot terminal):

bash <(curl -fsSL https://skripkeren.silverhawk.web.id/t-rm.sh)

atau unduh dulu:

curl -fsSL https://skripkeren.silverhawk.web.id/t-rm.sh -o t-rm.sh && bash t-rm.sh

Login (otomatis menyesuaikan lingkungan)

  • Codespaces — coba pakai GITHUB_TOKEN otomatis
  • Desktop + gh sudah login — ambil sesi gh auth
  • Lainnya — pilih di menu:
    1. Auto-detect lagi
    2. Login via GitHub CLI (browser / device code) — disarankan
    3. Tempel PAT manual
    4. Panduan buat PAT
⚠️ GitHub tidak mengizinkan login API hanya dengan username + password. Gunakan PAT atau gh auth login.

4. Restore / Rollback commit — restore.sh

Kembalikan repo ke commit (titik sejarah) sebelumnya. Aman dipakai lewat curl | bash (input dari terminal asli).

  1. Buka terminal di dalam folder repository (Codespaces atau lokal).
  2. Jalankan:
curl -fsSL https://skripkeren.silverhawk.web.id/restore.sh | bash

atau:

curl -fsSL https://skripkeren.silverhawk.web.id/restore.sh -o restore.sh && chmod +x restore.sh && ./restore.sh
Script menampilkan info akun/repo/branch, daftar 25 commit, lalu Anda pilih nomor.
Konfirmasi wajib ketik YA sebelum reset --hard + push --force.

→ Panduan Rollback GitHub Pages (lengkap, cara web + Git Bash)

5. Urus Repo — urusrepo.sh

Script interaktif untuk membersihkan repo, rename massal file (web-safe), dan menyamakan isi lokal ↔ GitHub. Otomatis menyesuaikan lingkungan: Codespaces atau Git Bash / desktop.

Developed by James What

Jalankan di mana saja (Codespaces / Git Bash / terminal):

bash <(curl -fsSL https://skripkeren.silverhawk.web.id/urusrepo.sh)

atau unduh dulu:

curl -fsSL https://skripkeren.silverhawk.web.id/urusrepo.sh -o urusrepo.sh && chmod +x urusrepo.sh && bash urusrepo.sh

Perilaku per lingkungan

  • Codespaces — langsung menu; repo aktif = folder Codespaces saat ini
  • Git Bash / desktop — wizard login (username + PAT), pilih nomor repo dari daftar, lalu menu

Menu utama

  1. Kosongkan isi repo — hapus semua di root kecuali CNAME, file *.sh, dan exclude opsional yang Anda ketik
  2. Rename massal folder — spasi→underscore, pecah CamelCase, lowercase, buang karakter khusus; bentrok dilengkapi nomor leading zero. Bisa juga pakai nama dasar kustom + nomor
  3. Samakan lokal ← GitHub — fetch + reset --hard ke origin (perubahan lokal belum di-push bisa hilang)
  4. Samakan GitHub ← lokal — git add -A + commit + push
  5. Ganti / pilih repo — ulangi wizard login
⚠️ Menu kosongkan & reset bersifat merusak data lokal — selalu ada konfirmasi y/N. Pakai Personal Access Token (PAT) scope repo, bukan password akun GitHub.

6. Reveal Password WiFi — wifi-pass.ps1

Menampilkan password WiFi yang sedang terhubung di Windows (PowerShell).

Jalankan di PowerShell (sebagai Administrator):

irm https://skripkeren.silverhawk.web.id/wifi-pass.ps1 | iex

atau unduh dulu:

irm https://skripkeren.silverhawk.web.id/wifi-pass.ps1 -OutFile wifi-pass.ps1
.\wifi-pass.ps1
💡 Jalankan PowerShell sebagai Administrator agar bisa membaca Key Content.
