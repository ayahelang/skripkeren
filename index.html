Auto dependency check

Semua file .sh ada di folder scripts/ · helper sk-deps.sh

Skripkeren by Ted

Klik nama script untuk membuka panduan + perintah siap salin ke terminal / CMD / console

Persiapan

Windows: pakai Git Bash. macOS/Linux: Terminal. Codespaces: terminal bawaan.

bash <(curl -fsSL https://skripkeren.silverhawk.web.id/scripts/installgitcli.sh)

Catatan urusrepo — salin antar repo (jaga SEO)

Menu [7] di urusrepo.sh: salin semua isi repo sumber ke repo tujuan tanpa menimpa file SEO / custom domain di tujuan (CNAME, robots.txt, sitemap*, ads.txt, humans.txt, security.txt, .well-known/).

Contoh: sumber ayahelang/sditdaarulistiqomah → tujuan ayahelang/darulistiqomah.
