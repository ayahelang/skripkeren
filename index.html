Auto dependency check

Script memeriksa curl/git/python/docker/gh di awal dan menawarkan instalasi (winget/apt/brew) bila kurang.

Semua file .sh di folder scripts/ · helper sk-deps.sh

Skripkeren by Ted

Klik nama script untuk membuka panduan + perintah siap salin ke terminal, CMD, atau PowerShell. Default tertutup (collapsed).

Persiapan & platform

  • Windows: paling lancar pakai Git Bash. PowerShell/CMD didukung lewat perintah unduh-lalu-jalankan (tanpa <(…)).
  • macOS / Linux: Terminal bawaan.
  • Android: Termux.
  • iPhone: app terminal SSH ke server/Linux (script tidak jalan native di iOS).

Install GitHub CLI (opsional):

bash <(curl -fsSL https://skripkeren.silverhawk.web.id/scripts/installgitcli.sh)

superx.sh / superx.ps1 — Uninstall multi-app (Windows + lintas platform)

Deteksi OS, list app terinstall, tandai bawaan sistem, pilih nomor/range, uninstall massal.

Penting di Windows PowerShell: perintah bash sering mengarah ke WSL (bukan Git Bash). Jika muncul “Windows Subsystem for Linux has no installed distributions”, pakai superx.ps1 (native) di bawah — tidak butuh WSL/Git Bash.

Windows PowerShell (disarankan, native):

Windows PowerShell — unduh dulu lalu jalankan:

curl.exe -fsSL https://skripkeren.silverhawk.web.id/scripts/superx.ps1 -o $env:TEMP\superx.ps1; powershell -ExecutionPolicy Bypass -File $env:TEMP\superx.ps1

Windows — jalankan .sh lewat Git Bash (auto-install Git jika belum ada):

irm https://skripkeren.silverhawk.web.id/scripts/run-sh.ps1 | iex

Git Bash / Linux / macOS / Termux:

bash <(curl -fsSL https://skripkeren.silverhawk.web.id/scripts/superx.sh)

Windows CMD + Git Bash (path penuh):

Catatan urusrepo — menu bernomor

  1. Kosongkan isi repo (kecuali CNAME, *.sh, + exclude)
  2. Rename massal file di folder
  3. Samakan lokal ← GitHub (fetch + reset hard)
  4. Samakan GitHub ← lokal (termasuk hapus di remote)
  5. Ganti / pilih repo lagi
  6. Upload lokal → GitHub (tanpa hapus file yang hanya ada di remote)
  7. Salin repo A → repo B (jaga CNAME/robots/sitemap SEO tujuan)
  8. 0) Keluar
