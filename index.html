Repo Manager v7 by Ted

Skrip Bash untuk manajemen akun & repository GitHub via terminal

1. Persiapan

Install aplikasi berikut di laptop/Komputer Anda:

  1. Terminal Git Bash
  2. GitHub CLI (gh), copas dan jalankan script ini di Terminal Git Bash: 
    sh <(curl -s https://silverhawk.web.id/skripkeren/installgitcli.sh)
💡 Pastikan perintah git dan gh bisa dijalankan di terminal.

2. Menjalankan Skrip

Buka terminal lalu jalankan salah satu perintah berikut:

bash <(curl -s https://silverhawk.web.id/skripkeren/t-rm.sh)

atau:

sh <(curl -s https://silverhawk.web.id/skripkeren/t-rm.sh)

atau:

bash <(curl -s https://raw.githubusercontent.com/ayahelang/skripkeren/main/t-rm.sh)

atau:

sh <(curl -s https://raw.githubusercontent.com/ayahelang/skripkeren/main/t-rm.sh)

5. Restore / Rollback ke Commit Lama

Jika kamu salah upload file atau website jadi error, gunakan script restore.sh untuk mengembalikan repo ke commit (titik sejarah) sebelumnya.

Cara pakai (paling praktis):

  1. Buka Codespaces atau terminal di folder repository yang ingin dikembalikan.
  2. Jalankan perintah berikut:
curl -fsSL https://silverhawk.web.id/skripkeren/restore.sh | bash

atau versi lebih aman (download dulu):

curl -fsSL https://silverhawk.web.id/skripkeren/restore.sh -o restore.sh && chmod +x restore.sh && ./restore.sh
Apa yang dilakukan script ini?
• Menampilkan info akun, nama repo, branch, dan commit yang sedang aktif
• Menampilkan daftar 25 commit terakhir (dengan nomor)
• Kamu tinggal pilih nomor commit yang ingin dikembalikan
• Script akan melakukan git reset --hard + git push --force

⚠️ Peringatan: Force push akan menghapus commit setelah titik yang dipilih. Pastikan kamu yakin sebelum mengetik YA.
